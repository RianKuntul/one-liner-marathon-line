One one-line comedy joke, up to 280 characters: the GPS says
"recalculating" in the exact tone of an ex being asked where the
relationship was going — both of them already knew I was lost.

## Run

```sh
node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–280 characters.
